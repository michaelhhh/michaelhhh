## Projects

**[VisaReady 485](https://github.com/michaelhhh/VisaReady)**
An agent-based pre-lodgement checker for Australia's Subclass 485 graduate visa. A case-officer agent audits a file across five refusal-risk areas, and a drafting agent turns each finding into a letter for human approval. Eligibility, deadlines and fees stay in a deterministic rules engine; language models only draft prose.
`Python` `Streamlit` `Pydantic` `PyMuPDF` `Gemini / OpenAI APIs` `pytest`

**[Automated fact-checking for climate claims](https://github.com/LinLeo29/COMP90042-NLP-Group-Project)**
Group project for Natural Language Processing at the University of Melbourne. I owned the evidence retrieval stage, progressing from a BM25 baseline to a fine-tuned bi-encoder hybrid, written up in a peer-reviewed ACL-format report.
`Python` `NLP` `Information retrieval`

**[Snowflake Cortex AISQL](https://github.com/michaelhhh/Snowflake-Cortex-AISQL)**
